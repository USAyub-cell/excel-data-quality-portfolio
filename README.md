# Excel Data Quality Portfolio

Professional Excel data-quality assessment example from Project APEX.

## Use case

Assess whether employee master data is sufficiently complete, validated, non-duplicated and governed for migration.

## Workbook capabilities

- executive data-quality overview;
- field-level profiling;
- record-level exception register;
- migration-readiness scoring;
- data-quality rule catalogue;
- reconciliation controls;
- structured, editable workbook design.

## Baseline

- 200 employee records
- 189 migration-ready
- 11 requiring remediation
- 94.5% readiness

## Portfolio note

Project APEX is a professional capstone consulting simulation using synthetic data.
